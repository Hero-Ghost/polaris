# Polaris - כוכב הצפון של המערכת שלך (Windows Diagnostics & Stability Suite)

**Polaris** היא סוויטה מתקדמת, מעוצבת וקלת-משקל לאבחון מעמיק, יציבות, בריאות ותחזוקת מערכת Windows.
התוכנה פותחה במיוחד כדי לתת מענה כולל ושקוף לכל בעיות הביצועים, הקריסות, והשאלה הנפוצה:
> **"למה המחשב שלי עומד על כמעט 90% זיכרון כשאני לא עושה כלום?"**

---

## ✨ יתרונות ויכולות מרכזיות

### 1. 🔍 אבחון שורש אוטומטי (Smart Root-Cause Diagnosis)
- **איחוד דפדפנים ואפליקציות כבדות**: מציג בצורה מרוכזת דפדפנים (Chrome, Edge, Firefox, Brave) ואפליקציות Electron (כגון Discord, Slack, Teams, VS Code) שמפצלות עשרות תהליכים נסתרים ברקע.
- **זיהוי דליפות זיכרון בדרייברים ובקרנל (Non-Paged Pool Leak)**: מזהה דליפות מוכרות של כרטיסי רשת (כמו Killer Network או שירות `ndu.sys`) ותוכנות אבטחה שצורכות זיכרון ללא שיוך לתהליך רגיל.
- **הבחנה בין זיכרון פעיל לזיכרון מטמון (Standby Cache)**: מסביר מתי ווינדוס מחזיק זיכרון כ-Cache כדי להאיץ את המחשב (וזמין לשחרור מיידי) לעומת תוכנות שתופסות זיכרון באופן פעיל.
- **הסבר מילולי בעברית ברורה**: סיכום ברור עם ציון בריאות (0-100) והמלצות מעשיות לפתרון.

### 2. ⚡ אופטימיזציה בלחיצה אחת (One-Click RAM Cleaner)
- כפתור **"שחרר זיכרון"** המשתמש ב-Windows API (`EmptyWorkingSet`) כדי לשחרר בבטחה דפי זיכרון רדומים מתהליכי רקע ולהחזיר מיידית מאות מגה-בייטים או ג'יגה-בייטים של RAM פנוי.

### 3. 📊 ממשק בסגנון כלי מערכת מקצועי
- **סרגל צד עם אחד-עשר מסכים נפרדים** - סקירה, תהליכים, אבחון זיכרון, בריאות כוננים, דרייברים והתקנים, תחזוקה ותיקון, תוכנות אתחול, קריסות, יומן שגיאות, כלי מקלדת והגדרות. כל נושא עומד בפני עצמו, בלי גלילה אינסופית שמערבבת דברים שאין ביניהם קשר.
- **מחווני מצב בניווט** - מספר התהליכים, ממצאים שדורשים טיפול, תוכנות אתחול כבדות וקריסות מסומנים ישירות על פריטי הסרגל, כך שרואים מה דורש תשומת לב בלי להיכנס.
- **מצב כהה ומצב בהיר** בלחיצת כפתור. הבחירה נשמרת ונטענת אוטומטית בהפעלה הבאה.
- צבע משמש רק כשהוא נושא מידע: אדום לבעיה, כתום לאזהרה, ירוק לתקין.
- תמיכה מלאה ב-**עברית (RTL)** וב-**אנגלית (LTR)** בלחיצת כפתור, כולל כל הטקסטים הנוצרים דינמית.
- גרף היסטוריית שימוש בזיכרון בזמן אמת (60 שניות אחרונות).
- תרשים התפלגות זיכרון מעגלי לפי קטגוריות (דפדפנים, פיתוח, שירותי מערכת, תוכנות משתמש, Non-Paged Pool).

### 4. 🗂️ סייר תהליכים מתקדם (Process Explorer)
- מעבר בין **מצב מקובץ** (הצגת אפליקציות עם אפשרות לפתיחת כל תהליכי הבן) לבין **מצב שטוח** (רשימת כל ה-PIDs).
- חיפוש וסינון מיידי לפי קטגוריות, זיכרון, וצריכת מעבד.
- אפשרות לסיום תהליך בודד או קבוצת תהליכים שלמה.
- חלון מידע מפורט (PID, נתיב קובץ, שורת פקודה, זיכרון פיזי ווירטואלי).

### 5. 🛠️ מרכז תיקון ותחזוקה (Revitalizer) ואבחון מסכים כחולים
- הרצה מבוקרת של כלי Microsoft רשמיים: `DISM /StartComponentCleanup`, `DISM /RestoreHealth`, `SFC /scannow`, איפוס Winsock ו-TCP/IP, איפוס Windows Update, ניקוי תור הדפסה, ו-TRIM ל-SSD — עם לוג חי.
- ניתוח יומן האירועים וקבצי Minidump לזיהוי BSOD, כיבויי פתע (Kernel-Power 41) ותרגום קודי BugCheck להסבר ופתרון בעברית.

---

### 6. 💽 בריאות כוננים (S.M.A.R.T.)
- קריאת מוני האמינות שהכוננים עצמם מדווחים: **אחוז בלאי ותוחלת חיים שנותרה** ב-SSD, **טמפרטורה**, **שעות פעילות**, ו**סקטורים פגומים** (שגיאות קריאה/כתיבה שלא תוקנו).
- מקום פנוי לכל אמצעי אחסון, עם אזהרה כשווינדוס נחנקת מחוסר מקום לקובץ ההחלפה ולעדכונים.
- כשמונה אינו זמין (הוא דורש הרשאות מנהל), התוכנה **אומרת זאת במפורש** במקום להציג "תקין" מנוחש.

### 7. 🔌 דרייברים והתקנים בעייתיים
- כל ההתקנים שווינדוס סימנה בתקלה — המשולשים הצהובים ב-Device Manager — עם **תרגום קוד התקלה המספרי** (43, 28, 10, 31...) להסבר בעברית ולפעולה מומלצת.
- איתור **דרייברים ישנים** (מעל 4 שנים) לכרטיס מסך, רשת ואחסון. דרייברים מובנים של Microsoft אינם נספרים — התאריך שלהם הוא תאריך שחרור Windows.
- **חיבור למנתח המסכים הכחולים**: כשקריסה מאשימה את `rt640x64.sys`, המסך מתרגם זאת ל"כרטיס רשת קווי Realtek" ומציג את גרסת הדרייבר המותקנת. קובץ שאינו במאגר מדווח ככזה, בלי ניחושים.

### 8. 📋 יומן שגיאות מערכת
- שגיאות ואירועים קריטיים מיומני System ו-Application, **מקובצים לפי מקור ומזהה אירוע** ומדורגים לפי חשיבות ולא לפי כמות.
- מאגר הסברים בעברית לשגיאות הנפוצות: בלוקים פגומים בדיסק, פגיעה ב-NTFS, שירותים שקורסים, קריסות תוכנה, כשלי TLS ועוד.
- **סינון רעש**: אירועים כמו DistributedCOM 10016 שמופיעים בכל מחשב תקין מסומנים כרעש ומוסתרים כברירת מחדל, כך ששגיאת דיסק בודדת לא נבלעת בין מאה הודעות חסרות משמעות.

## 🔒 אבטחה ופרטיות

- השרת המקומי מאזין **רק** על `127.0.0.1` ואינו נגיש מהרשת.
- כל קריאה ל-`/api/` מחייבת **טוקן סשן** שנוצר מחדש בכל הפעלה ומוזרק ל-`index.html`. אתר חיצוני שנפתח בדפדפן אינו יכול לקרוא את הטוקן ולכן אינו יכול לסגור תהליכים או להריץ DISM דרך Polaris.
- כותרות `Host` ו-`Origin` נבדקות (הגנה מפני DNS-Rebinding), ולא נשלחות כותרות CORS כלל.
- שמות תהליכים שמגיעים ממערכת ההפעלה עוברים escaping לפני הצגה, ומאומתים לפני שהם מועברים ל-`taskkill` / PowerShell.
- אין תקשורת יוצאת: Chart.js ארוז מקומית תחת `frontend/vendor/`, וגיליון הסגנונות נכתב ידנית ללא CDN או framework חיצוני. התוכנה עובדת במלואה גם ללא אינטרנט.

> **הרשאות מנהל:** ניטור וניהול תהליכים עובדים ללא הרשאות מיוחדות. כלי התיקון (DISM/SFC/רשת/הדפסה/TRIM) דורשים הרשאות מנהל — אם Polaris לא הורץ כמנהל, יוצג באנר אזהרה בממשק.

## 🚀 איך מריצים?

### דרך 1: הרצת קובץ ה-EXE העצמאי (הכי מומלץ - קובץ יחיד!)
- פשוט לחץ לחיצה כפולה על הקובץ היחיד **`Polaris.exe`** הנמצא בתיקייה הראשית.
- קובץ זה מכיל הכל בתוכו (קוד, ממשק גרפי, שרת מובנה ומאגר ידע), וניתן להעתיק אותו ישירות לכל מחשב או דיסק-און-קי ולהריץ אותו מיידית!

### דרך 2: הרצה באמצעות סקריפט
- לחץ לחיצה כפולה על הקובץ **`Run-Polaris.bat`**.

### דרך 3: הרצה דרך שורת הפקודה (Terminal / PowerShell)
```powershell
pip install -r requirements.txt
python main.py
```

אפשרויות שורת פקודה:

| דגל | תיאור |
|---|---|
| `--cli` | אבחון מהיר בטרמינל, בלי ממשק גרפי |
| `--server-only` | הפעלת השרת בלבד (למשל לפתיחה בדפדפן חיצוני) |
| `--port 5789` | קביעת פורט ידנית (ברירת מחדל: הפורט הפנוי הראשון מ-5789) |
| `--version` | הצגת גרסה |

### בנייה מחדש של קובץ ה-EXE
```powershell
python package_exe.py
```

## 🌐 REST API

כל הנתיבים מחייבים כותרת `X-Polaris-Token` עם הטוקן מ-`<meta name="polaris-token">`.

| שיטה | נתיב | תיאור |
|---|---|---|
| GET | `/api/stats` | נתוני זיכרון בזמן אמת + היסטוריה (דגימה אחת בשנייה) |
| GET | `/api/diagnose` | ציון בריאות, ממצאים והמלצות |
| GET | `/api/processes` | רשימת תהליכים (`grouped`, `search`, `category`) |
| GET | `/api/process_details` | פרטי תהליך והסבר מעמיק (`pid`, `name`) |
| GET | `/api/services` | מיפוי שירותי Windows לתהליכים מאחסנים |
| GET | `/api/crashes` | היסטוריית BSOD וכיבויי פתע, כולל שיוך הדרייבר לחומרה |
| GET | `/api/disks` | בריאות כוננים: S.M.A.R.T., בלאי, טמפרטורה, קיבולת וממצאים |
| GET | `/api/devices` | התקנים תקולים, קודי תקלה ודרייברים ישנים |
| GET | `/api/events` | שגיאות חוזרות ביומן האירועים (`days`, 1-30) |
| GET | `/api/system_info` | הרשאות מנהל, פלטפורמה, מצב אריזה |
| GET | `/api/revitalize/audit` \| `/progress` | בדיקת מצב ותקדמות תחזוקה |
| GET | `/api/startup/apps` | תוכנות שעולות בהדלקה ודירוג השפעה |
| POST | `/api/optimize` | שחרור Working Sets בכל המערכת |
| POST | `/api/kill` | סגירת תהליך (`pid`) או קבוצה (`group_name`) |
| POST | `/api/trim_process` \| `/api/trim_group` | שחרור זיכרון ממוקד |
| POST | `/api/revitalize/start` | הפעלת תחזוקה עם `options` |
| POST | `/api/memory_diagnostic` | הפעלת `mdsched.exe` לבדיקת RAM |
